[IN PRODUCTION]

The backend for India's first QKD network, used in defense. Quantum nodes generate encryption keys; the platform decides who can use them, keeps the nodes healthy and moves events between them reliably.

  • An on-prem AI copilot so operators can run the network in plain language.
  • Multi-architecture builds (amd64 and arm64) and one release process across every repository.

E-ink Quran and library reader

[IN PROGRESS]

An offline-first e-ink reader built on an ESP32-S3, with a desktop app that converts books and sends them to the device. It works with no internet at all; Wi-Fi and Bluetooth are only for setup and sync.

  1. Desktop appTauri app: add PDF, EPUB or text
  2. Convertervalidates and previews before install
  3. Packagecustom binary format, byte-identical on both sides
  4. Uploadresumable, atomic, safe on power loss
  5. DeviceESP32-S3 renders to e-paper from SD
  • Firmware for the display, SD card, buttons, rotary wheel and deep sleep, verified on real hardware.
  • 198 host tests on the firmware, with power loss simulated at every write during install.
  • Bluetooth first-boot setup, and a table-clock home screen with Wi-Fi time sync and a rotating greyscale photo.
